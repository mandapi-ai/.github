# MandAPI AI

**Gateway multimodelo de IA para desenvolvedores.**

GPT · Claude · Gemini · DeepSeek · Kimi · GLM · MiMo

Uma API para aplicações, agentes e automações, com foco inicial nas necessidades de quem desenvolve no Brasil. Explore modelos de ponta e alternativas econômicas usando um gateway, uma chave e formatos de integração conhecidos.

[Site](https://mandapi.com/) · [Documentação](https://mandapi.com/docs) · [Modelos](https://mandapi.com/#/models) · [Preços](https://mandapi.com/pricing)

## API de IA no Brasil 🇧🇷

A MandAPI reúne:

- **Preços em reais (BRL)** para comparar entrada e saída.
- **Recarga via Pix** para adicionar créditos de uso.
- **API compatível com OpenAI**, conforme o contrato documentado.
- **Modelos de IA baratos** e modelos premium para diferentes tarefas.
- **Documentação e guias em português**, com configuração e diagnóstico.

Confirme o ID, o protocolo e a disponibilidade do modelo antes de integrar. O suporte varia entre modelos e gateways.

## Comece pelo Developer Kit

O [**Developer Kit**](https://github.com/mandapi-ai/developer-kit) já contém dois pacotes utilizáveis a partir do código do repositório:

- **Codegen:** gera requisições sem streaming para quatro protocolos e sete linguagens, com URL base configurável.
- **Catalog:** oferece consulta, filtros e seleção de protocolo a partir de declarações explícitas, em um snapshot estático de nove modelos reais.

Os pacotes **ainda não foram publicados no npm**. O README explica como instalar as dependências, compilar e gerar seu primeiro exemplo. Campos desconhecidos do catálogo são omitidos; nomes de modelos não determinam o protocolo.

A [validação P2](https://github.com/mandapi-ai/developer-kit/blob/main/docs/p2-validation.md) registra uma chamada Python real de `gpt-6-sol` via Chat. Esse resultado não representa testes ao vivo de todos os modelos ou protocolos.
