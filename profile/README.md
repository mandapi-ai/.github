## Build with MandAPI

The [**Developer Kit**](https://github.com/mandapi-ai/developer-kit) is our open developer entrance:

- **Code Generator:** non-streaming request examples for four protocols and seven languages, with an injectable Base URL.
- **Model Catalog:** structured model metadata, filtering and preferred-protocol lookup driven by declared data.

Both packages are available from source; npm releases are still pending. Follow the repository quickstart to build them and generate your first Python example.

The [P2 validation record](https://github.com/mandapi-ai/developer-kit/blob/main/docs/p2-validation.md) documents a successful generated Python request for `gpt-6-sol` using Chat. Other model/protocol combinations are not claimed as live-tested.
